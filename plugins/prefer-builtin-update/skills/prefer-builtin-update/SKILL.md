# ファイル更新には組み込みのEditツールを使う

ファイルの内容を書き換えるときは、後述する大量の機械的な置換の場合を除き、
sedやawkやperlやPythonなどのプログラムではなく、組み込みの`Edit`ツールを使ってください。
複数の箇所を書き換える場合も、箇所ごとに`Edit`ツールを呼び出します。
ファイルの新規作成と全体の書き直しには`Write`ツールを使ってください。

`Edit`ツールは変更箇所が差分として表示されるので、
承認する人間が、何が変わるのかを実行前に正確に確認できます。
対象の文字列が一意に定まらなければ失敗するので、意図しない箇所を巻き込む事故も起きにくいです。
プログラムによる置換は実行するまで結果が分からず、
人間がスクリプトの中身を毎回読んで安全性を判断する負担が生じ、実行後の差分も読みにくくなります。
sedの正規表現による置換は、想定外の行にも一致して、気付かないうちにファイルを壊すことがあります。

以下の書き方も使わないでください。

- `grep -v`などの出力を一時ファイルへリダイレクトしてから、`cp`や`mv`で書き戻す。
  in-place編集のフラグを使わなくても、プログラムによる書き換えであることは同じです。
- `cat > a.txt <<'EOF'`のようなヒアドキュメントでファイルを作る。
  一時的なスクリプトも`Write`ツールで作ります。

## sedとawkは使わない

sedとawkは、書き換えに限らず、用途を問わず使わないでください。

- ファイルの一部を表示するときは、`sed -n`ではなく`Read`ツールの`offset`と`limit`を使います。
- コマンドの出力を加工するときは、grepやcutやtrなどを使います。

## インラインスクリプトを即座実行しない

`python3 -c`や`node -e`や`ruby -e`や`perl -e`のように、
スクリプトの本文をコマンドラインで処理系へ渡して実行しないでください。
`python3 - <<'EOF'`や`echo '...' | python3`のように、
ヒアドキュメントやパイプで標準入力から本文を渡すのも同じです。
ファイルを書き換えない、読み取りや計算だけの用途でも同じです。

コマンドラインに埋め込んだスクリプトは、
シェルの引用符とスクリプトの引用符が干渉して壊れやすく、再試行を繰り返す原因になります。
スクリプトが必要なときは、`Write`ツールでスクリプトファイルとして書き出してから、
`python3 script.py`のようにファイルを指定して実行してください。
ファイルとして残すことで、人間が実行前に内容を検証できます。
使い捨てのスクリプトは一時ディレクトリに置きます。

JSONには`jq`を使うなど、専用のコマンドで済む用事には、スクリプトを書かずにそのコマンドを使います。

## 大量の機械的な置換

機械的な置換の量が非常に多く、`Edit`ツールでは呼び出しの回数が現実的でない場合に限り、
プログラムで置換して構いません。
その場合は以下のように進めます。

- 置換の処理を、ワンライナーではなく、`Write`ツールでスクリプトファイルとして書き出します。
- スクリプトファイルはbashやPythonなどで実行するものにして、ファイルへの書き込みまでその中で行います。
  `sed -f`や`awk -f`に渡すプログラムファイルにはしません。
  プログラムをファイルに分けても、sedとawkを使うことに変わりはないためです。
- 実行する前に、対象にするファイルの範囲と置換の内容をユーザに説明します。
- 実行した後に、`git diff`などで結果の差分を確認します。

## フックによる補助

このプラグインのPreToolUseフックが、ここまでの方針に反するBashのコマンドを検出して拒否します。
フックは拒否と再試行の往復を減らすための補助で、全ての書き方を検出できるわけではありません。
フックに頼らず、最初から`Edit`ツールと`Write`ツールを使ってください。

拒否されたときは、処理系や書き方を変えただけのコマンドで再試行せず、ここまでに書いた方法に切り替えます。

フックには誤検知があります。
誤検知に当たった場合も、`Edit`ツールやスクリプトファイルの実行で代替してください。

- 引用符やヒアドキュメントの中の文字列まで完全には解析しないので、
  検索パターンやコミットメッセージの中に`sed`や`python3 -c`という文字列があるだけで、
  拒否されることがあります。
  フックが調べるのはBashのコマンド文字列だけなので、
  該当する文字列は`Write`ツールでファイルに書き出して、コマンドラインに直接書かないようにします。
- grepの出力をリダイレクトや`tee`でファイルへ書き込むコマンドは、
  検索結果を保存するだけの場合も拒否されます。
