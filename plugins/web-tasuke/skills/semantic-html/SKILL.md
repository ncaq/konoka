# セマンティックHTML

意味のある構造には、`<div>`ではなくセマンティックHTML要素をなるべく使ってください。
セマンティックHTML要素は、アクセシビリティツールにもLLMにも人間にも読みやすいからです。
`<div>`にコメントで意味を補足するくらいなら、その意味を表す要素を選びます。

```tsx
// 避ける
<div>
  <h3>承認セクション</h3>
  <textarea />
  <button>承認</button>
</div>

// 良い
<section>
  <h3>承認セクション</h3>
  <textarea />
  <button>承認</button>
</section>
```

## 要素の使い分け

- `<main>`: ページの主要コンテンツです。
  1ページにつき1つだけ使います。
- `<article>`: 独立して意味をなすコンテンツです。
  ブログ記事、コメント、カードなどが該当します。
- `<section>`: 見出し(`<h1>`から`<h6>`)を伴うコンテンツのまとまりです。
  ページ内の各セクション、フォームのグループなどが該当します。
- `<header>`: セクションやページの導入部分です。
  タイトル、ロゴ、ナビゲーションなどを含みます。
- `<footer>`: セクションやページの末尾です。
  関連リンク、アクションボタン群などを含みます。
- `<nav>`: 主要なナビゲーションリンクのまとまりです。
  サイドバーメニュー、パンくずリスト、ページ内リンクなどが該当します。
- `<aside>`: メインコンテンツに対する補足情報です。
  サイドバー、注釈、関連リンクなどが該当します。

## `<div>`を使ってよい場合

`<div>`は、意味を持たないコンテナにだけ使います。

- FlexboxやGridなど、レイアウトのためのラッパー
- スタイリングのためだけのグルーピング
- 上記のどのセマンティックHTML要素にも該当しないコンテナ
